# Three-Minute Demo Script

## 0:00–0:20 — Hook

“An agent can be brilliant and still be dangerous. Veylock lets the model propose any action while Solana decides whether capital is allowed to move.”

## 0:20–0:50 — Mandate

Open the control room. Show the separate authority, allowed assets, $500 action limit, $2,000 daily budget, 8% breaker, and paper mode.

## 0:50–1:25 — Agent intent

Generate an intent with Groq. Point out that model confidence is displayed but never used as authorization. Read the thesis and invalidation in one sentence.

## 1:25–1:55 — Deterministic verdict

Walk through the four checks. Reduce the max action below the proposal and show the verdict switch to Blocked. Restore the limit and show Authorized.

## 1:55–2:25 — Solana proof

Connect Phantom on devnet and write the receipt. Open the explorer transaction. Explain that the receipt is the lightweight web MVP path.

## 2:25–2:45 — Program

Show the Anchor source: policy PDA, funded vault, paper mode, budget, drawdown breaker, allowlist, halt, nonce, and intent hash.

## 2:45–3:00 — Close

“Trading is only the first workflow. Veylock is the control plane for any software that receives economic agency.”
