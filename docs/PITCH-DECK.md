# Veylock Pitch Deck

## 1. Cover

**Veylock**  
Execution firewall for autonomous capital.

## 2. Problem

Agents can now reason, plan, and sign. The missing layer is enforceable authority. Application-level guardrails disappear when code is compromised, prompts are injected, or a model behaves outside expectations.

## 3. Insight

Intelligence and authority should not share the same trust boundary. The model may propose anything. Capital should move only when a separate policy engine approves it.

## 4. Product

Veylock turns a human mandate into deterministic transaction rules: approved assets, per-action ceilings, daily budgets, drawdown breakers, paper mode, and emergency halt.

## 5. Demo

1. Ask Groq for a trade intent.
2. Watch Veylock evaluate every rule independently.
3. Tighten a limit and see the same intent blocked.
4. Submit an allowed receipt to Solana devnet.
5. Show the compiled Anchor vault program and program ID.

## 6. Architecture

Agent framework → intent contract → policy preflight → Solana policy vault → recipient / protocol.

## 7. Beachhead

Autonomous crypto treasury teams need bounded rebalancing before they trust agents with meaningful funds.

## 8. Expansion

Treasury → market making → payroll → procurement → machine payments → cross-chain policy control.

## 9. Business

Free SDK and devnet templates. Paid authorization volume, team policy management, observability, compliance exports, and enterprise deployment.

## 10. Moat

Policy graph, integration surface, battle-tested templates, incident data, wallet distribution, and an auditable execution history.

## 11. Roadmap

- Token-2022 and SPL vault execution
- Jupiter CPI adapter with slippage and route restrictions
- Signed policy templates and SDKs
- Multi-agent shared budgets
- External audit and mainnet pilot

## 12. Ask

Design partners operating agent-controlled treasuries, wallet integrations, and security reviewers for the first production pilot.
